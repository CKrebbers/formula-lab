# Family packs — AI-generated generations of formula families

A pack is one GENERATION of 10 formulas, generated by any LLM from a prompt
that is seeded with the user's own memory: rated snapshots, saved formulas,
working habits (origins/coords) and elites-grid discoveries. Packs live next
to the built-in library, stay separate per generation, and can be toggled
on/off or deleted at any time — a preference bank that keeps unlocking more
of what the user most loves to see.

## Workflow

1. In the app: `packs` → **copy AI prompt**. The prompt is rebuilt live from
   localStorage each time, so a later generation reflects a richer history.
2. Paste the prompt into any model (Claude, Gemini, local Ollama…).
3. The model answers with ONLY this JSON (10 families, one direct list):

```json
{
  "name": "crt-spirits",
  "families": [
    { "name": "Radar sweep",
      "source": "sin(length(x * 6.0, y * 6.0) * 8.0 - t * 4.0) * step(0.3, fract(th * 3.0))",
      "coords": "cartesian",
      "notes": "circular sweep over segmented rings — echoes the rated radial pieces" }
  ]
}
```

4. Paste that JSON into the `packs` panel → **import pack**. Every formula is
   compiled through the real parse→transpile pipeline; invalid ones are
   dropped and reported, valid ones enter as a new generation.

## Guarantees

- **Generations stay apart**: each pack is its own unit (own id, timestamp,
  optgroup in the family picker). Toggling a pack off removes its families
  from the picker AND from the zero-player's gene pool; deleting is permanent.
- **Nothing unvalidated enters**: `families/packs.js` runs each source through
  parse → extractParams → transpile before accepting it.
- **The taste loop closes**: snapshots saved from pack families record
  `family: <pack>.<n>`, so the NEXT prompt's history shows which generations
  actually got used and loved — each generation trains the following one.

## For the generating AI

The copied prompt is self-contained: grammar whitelist, safety rules (no `^`
on negative bases), the user's memory digest, and the strict output shape.
Honor it literally — especially "JSON only" and "exactly 10". Formulas should
carry 3–8 numeric literals (they become live sliders/automation targets) and
animate on `t`.
